# セキュリティの不安を軽減

医療・介護・福祉に関わるセラピスト向けの、日本語のIT・ネットワーク・クラウド・情報セキュリティ基礎学習サイトです。

公開URL: https://security.hiluco.net/

## 内容

- 全12回。各回に仕組みの説明、図解、架空の現場事例、実践課題、解説付きの3〜4択問題。第1〜7回は各3問、第8〜11回は各5問、第12回は最終10問の計51問。第8回に同期・バックアップの体験図、第9回にCIA分類3ケース、第11回に9項目のセルフチェック、第12回に3ケースの初動演習。
- 全問正解で学習済み。ブラウザ内に解答・最新得点・最高得点・進捗を保存。
- 検索できる用語集、教材の印刷、進捗削除。
- スマートフォン対応、キーボード操作、縮小動作設定対応。
- 学習データのサーバー送信、ログイン、アクセス解析、外部フォントなし。

## 教材の出典と位置付け

ユーザー提供の共有スレッド（https://chatgpt.com/share/6adab7d9-0818-83e8-9849-6c1816a5c886）と追加提供テキストから、第8〜12回の本文を反映しました。確認問題は提供内容をもとに解説付きで補完しています。第1〜7回の本文は未提供のため、同スレッドの総復習で示された全12回の構成に沿って補完しています。元チャットの完全な転載ではありません。

参考資料へのリンクはサイト内の「この講座について」に掲載。IPAの基本対策と厚生労働省の医療情報システム安全管理の公式資料を案内しています。内容は一般的な入門学習であり、個別施設の安全管理規程や公式ガイドラインへの適合審査を代替しません。

## 開発・検証

Node.js 24推奨。

```sh
npm ci
npm run check
npx playwright install chromium
npm test
node scripts/preview.mjs
```

プレビュー: http://127.0.0.1:4173/

`npm run check` はJavaScriptの構文、12回分の必須教材、51問と実践演習の正解・選択肢を検証して `dist/` を生成します。`npm test` は実ブラウザで320px/375px/1280pxの全教材表示、採点、進捗復元、検索、削除、保存不可時を検証します。画面キャプチャは `SCREENSHOT_DIR` を指定しない場合はテスト実行を省略します。

## 教材の編集

`public/lessons.json` に全教材を集約しています。タイトル・説明・図解の段階・事例・実践課題・用語・確認問題を編集した後、`npm run check` と `npm test` を実行してください。

## 復旧

初回公開前に同名Workerや同名カスタムドメインはありません。更新後に問題があれば、Cloudflareの対象Workerのデプロイ履歴から直前の正常な版へ戻します。サイト削除時は対象のカスタムドメインとWorkerだけを削除し、ゾーン全体やメール関連レコードを削除しないでください。ブラウザ内進捗は、キー `care-digital-progress-v1` を維持する限り同一オリジンで引き継がれます。

教材構成の更新はrevisionで管理します。既存の保存キーは維持し、旧版の記録は保持します。更新版は未確認として扱い、再採点時にpreviousへ旧版履歴を残します。新しい教材や問題へ変更する際は該当回のrevisionも更新してください。セルフチェックは修了判定から独立して保存します。
